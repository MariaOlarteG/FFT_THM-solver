# FFT_THM-solver

This Fast Fourier Transform (FFT)-based solver simulates the thermoporomechanical behavior (including non-linearity) of  infinitely contrasted porous materials, by employing the Adaptive Eyre--Milton (AEM) algorithm as an enhanced iterative algorithm. 

Please consider citing the following article if you find this algorithm useful:

Olarte-Garzon, M., Dangla, P., & Pereira, J. M. (2027). FFT-based solver for upscaling the thermoporomechanical behavior of infinitely contrasted porous materials. Computers and Geotechnics, 201, 108526.
